# Release v0.6.0 — Document Understanding

**Phase**: 6 of 7 (see project roadmap)
**Status**: Complete

## What's included

- **`neural_network` added to `ClassifierFactory`** (FR1): an
  `MLPClassifier` (feedforward network) plugged into the existing
  Pipeline/cross-validation code with zero changes to the
  training/evaluation logic — the second real proof of Feature 0003's
  extensibility design.
- **`compare` CLI command** (FR2/FR3/FR4): cross-validates Logistic
  Regression and the neural network side-by-side against the
  majority-class baseline, in one run, and persists whichever performs
  best.

## A genuine hypothesis, honestly tested

This feature set out to test whether a neural network improves on
Phase 3's Logistic Regression baseline — not to assume it would.

| Model | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| Baseline (majority class) | 17.5% | 2.2% | 12.5% | 3.7% |
| **Logistic Regression** | **83.5%** | 85.9% | 82.0% | 82.3% |
| Neural Network (MLP) | 79.0% | 78.8% | 78.3% | 77.5% |

The simpler linear model won by ~4.5 points of accuracy — consistent
with the well-established pattern that neural networks need
substantially more data than ~200 examples to outperform strong linear
baselines on bag-of-words text features. `compare` correctly persisted
Logistic Regression as the default artifact, since it picks the actual
winner rather than favoring either model.

## An explicit, honest scope decision

The roadmap names three Phase 6 techniques: advanced classification,
table extraction, and OCR. Only the first had real content in this
project's synthetic corpus to validate against — no generated PDF
contains an embedded table (structured data lives only in the Excel
generator's output), and every PDF is text-native, not scanned.
Building either technique now would mean writing code with nothing
real to prove it works, contradicting this project's own
"measured, not assumed" discipline (Feature 0005). Both remain concrete
Future Improvements, with the actual prerequisite named: documents that
genuinely contain tables or scanned content, which don't exist yet.
